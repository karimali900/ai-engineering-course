## How to use this library

1. **Read in order.** The modules build on each other; Module 0 is a short orientation, then Modules 1–17 go from ML foundations to frontier ideas.
2. **Use the HTML reader for study.** It has a full-text search, a per-lesson table of contents, and checkboxes that remember what you have read in your browser.
3. **Annotate the Markdown.** Each lesson is a self-contained `.md` file. Add your own notes below the article, or keep a separate notes file.
4. **Use the PDFs for offline reading.** Each module has a PDF, and there is one full-course PDF.
